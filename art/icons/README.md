# Icons for the in-game phone

Drop PNG app icons here, made with an image AI in ONE consistent style (glossy 3D app icon, rounded square, iPhone style). See docs/reference/phone_target.jpg.

Name each file after its app: items.png, jobs.png, map.png, shop.png, settings.png, braintalks.png, braintok.png, bank.png, badges.png, help.png, phone.png, messages.png, contacts.png.

Claude uploads them with the Open Cloud key and connects them in PhoneOS.lua.
